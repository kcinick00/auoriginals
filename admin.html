Conexión con GitHub

Para publicar desde el teléfono, este panel necesita permiso para guardar en tu repositorio. Se configura una sola vez y el permiso queda guardado solo en este teléfono.

¿Cómo consigo el token?
  1. En GitHub abre Settings → Developer settings → Personal access tokens → Fine-grained tokens y toca Generate new token.
  2. En Repository access elige Only select repositories y marca solo tu repositorio de AU Originals.
  3. En Permissions → Repository permissions pon Contents: Read and write.
  4. Genera el token, cópialo y pégalo arriba.

Pon la caducidad más larga que permita GitHub. Cuando caduque, genera otro y pégalo aquí.
